Independent project · Kotlin / IntelliJ Platform

Doppler Secrets for IntelliJ

An independently developed, unofficial plugin that brings Doppler secrets into IntelliJ: browse, edit, sync, and launch with fresh values from the IDE.

The problem
Switching between the IDE and a secrets dashboard interrupts development and invites manual copying.
The solution
Edit secrets in memory with two-way sync, then inject fresh values into Run and Debug launches.
The benefit
Keep secrets in your development workflow without saving them in project files.
  • In-memory secret editing
  • Run & Debug integration
  • Signed releases & SBOMs
  • Build provenance attestations
